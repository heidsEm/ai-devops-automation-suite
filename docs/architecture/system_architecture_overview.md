# System Architecture Overview

This portfolio integrates multi-platform AI workflows, media generation pipelines, cloud API management, and DevOps governance tools into a unified automation suite.

```
                    ┌────────────────────────────────────────┐
                    │      n8n Orchestration Engine          │
                    └──────────────────┬─────────────────────┘
                                       │
           ┌───────────────────────────┼───────────────────────────┐
           ▼                           ▼                           ▼
┌─────────────────────┐     ┌─────────────────────┐     ┌─────────────────────┐
│  AI Video Pipelines │     │   Media Generation  │     │  Cloud & API Ops    │
│  - Claude Scripting │     │  - ElevenLabs TTS   │     │  - Apigee Edge/X    │
│  - HeyGen Avatars   │     │  - Video Overlay    │     │  - Azure APIM       │
│  - Content Prompts  │     │  - EOD Summary      │     │  - GitHub Workflows │
└─────────────────────┘     └─────────────────────┘     └─────────────────────┘
```

## Core Technology Layers

1. **AI & Speech Orchestration:** n8n, Claude API, ElevenLabs API, HeyGen API.
2. **Media & Canvas Processing:** HTML5 Canvas, Web Audio API, FFmpeg WebAssembly.
3. **API & Cloud Management:** Apigee Edge/X, Azure APIM, Azure DevOps.
4. **DevOps & Repository Governance:** GitHub Actions, Python Automation, OpenSSL PKI.
